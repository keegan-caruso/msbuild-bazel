# Shared sync defaults and diagnostics

Stage 4 of the [roadmap](roadmap.md) adds optional `projectDefaults` with explicit
project overrides. The [mapping API](project-sync.md#shared-project-defaults)
defines precedence and rejected cases. Normal SDK/global.json application setup
does not need another configuration file.

The fixture's `defaults.py` factors only identical existing values and whole
reviewed document contracts. It does not discover or approve custom inputs.
Both upstream preparation helpers now emit this form, including the runtime tool
bootstrap closure.

| Graph | Before | After | Reduction | Generated output |
| --- | ---: | ---: | ---: | --- |
| HTTP, 44 projects | 522,340 bytes | 162,705 bytes | 68.9% | Byte-identical |
| Immutable, 36 projects | 531,126 bytes | 285,161 bytes | 46.3% | Byte-identical |

The byte comparison includes every generated source, dependency, tool, package,
custom input and test declaration. `--check` and repeated sync pass with the
compacted mappings. They retain the stage-3 action inputs and cache identities.

Small synthetics cover inherited defaults on unlisted transitive projects,
project overrides, explicit empty lists and booleans, complete document-contract
replacement, stale import rejection and unchanged output after failures. Unknown
fields, unsafe paths, invalid tool labels and duplicate/ambiguous keys fail.
Project/configuration context and mapping guidance are checked for unknown item
and custom-target errors. No custom-document hash is automatically updated.

Reproduce the graph comparison after the stage-2 setup:

```sh
python3 tests/project_sync/defaults.py WORKSPACE BAZEL_BASE NEW_REPORT_DIRECTORY
```

The helper keeps the original mapping in its report directory, checks the compact
mapping against the existing generated bytes, then repeats synchronization. On
failure it restores the original mapping. The resulting graph remains explicit
and reviewable in `projects.generated.bzl`.

[Compact evidence](project-sync-defaults-evidence.json) records the graph comparison,
40 sync/normalization controls, owned-code build/style checks and small app
acceptance on Bazel 8.8.0 and 9.2.0. Scaffold/Starlark checks also pass.
